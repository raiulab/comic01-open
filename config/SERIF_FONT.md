# セリフ用フォント設定（serif-font.json）

漫画の**セリフ（台詞）**を、生成時とテキストオーバーレイ（フェイルセーフ）の両方で同じフォントにそろえるための設定です。

## 設定ファイル

- **config/serif-font.json** に次の形式で指定します。

```json
{
  "name": "Noto Sans JP",
  "path": "font/NotoSansJP-Regular.ttf"
}
```

- **name**: 画像生成AI用のプロンプトに使うフォント名（「〇〇のようなゴシック体で描く」と指示します）
- **path**: オーバーレイ描画で使う TTF ファイルのパス（プロジェクトルートからの相対パス）

## フォントの入手

- **Noto Sans JP**（Google Fonts）
  https://fonts.google.com/noto/specimen/Noto+Sans+JP
  「Download family」から ZIP を取得し、中にある **NotoSansJP-Regular.ttf** をプロジェクトの **font/** に配置してください。
- ファイル名が異なる場合（例: NotoSansJP-VariableFont_wght.ttf）は、**path** をその名前に合わせて変更してください。

## 挙動

- **漫画生成時**: プロンプトに「吹き出し内の文字は、{name} のようなゴシック体のサンセリフで、読みやすく統一して描くこと」が追加され、AI がそのスタイルに近い文字を描くようになります。
- **テキストオーバーレイ時**: **path** で指定した TTF が存在すればそのフォントで描画し、存在しなければシステムの日本語フォント（Hiragino / Yu Gothic 等）にフォールバックします。
- **config/serif-font.json が無い、または不正**な場合は、生成時はフォント指定なし、オーバーレイ時はシステムフォントのみになります。

## 画像生成時のセリフフォントについて

- **指定できるのは1種類だけです**。`serif-font.json` の **name** が、画像生成プロンプトで「〇〇のようなゴシック体で」と AI に渡されます。この name を変えれば、生成時に指示するフォント名だけを切り替えられます（例: "Noto Sans JP" → "M PLUS 1p"）。
- **日付・シナリオ・画風が変わるとセリフの見た目が毎回変わる問題**: プロンプトに「【吹き出しの文字（全生成で統一・絶対厳守）】画風・シナリオ・日付に依存せず、吹き出し内の文字は常に〇〇で統一すること」というブロックを**画風の直後**で明示しており、統一されるよう促しています。ただし **AI は実際の TTF を使わず描画する**ため、完全に同じ見た目になる保証はありません。
- **AI は実際の TTF を使いません**。画像モデルは「〇〇のような」という説明を解釈して、そのスタイルに*近い*文字を**描画**します。そのため、コマごと・生成ごとに太さ・字間が少しずつ違って見えることがあります。
- **完全に同一フォントにしたい場合**: 生成後に、テキストオーバーレイ（Inpaint の overlay モード）で **path** の TTF を上書きすると、指定した1種類のフォントに統一できます。
