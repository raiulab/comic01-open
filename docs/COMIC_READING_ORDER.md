# 漫画の読順・表示順序（必ず守る設計思想）

このドキュメントは、**日本の漫画は右から左へ読む**という前提に基づく、コマ・セリフの表示順序に関する設計思想です。
新機能追加・リファクタ・レイアウト変更の際は、この内容を破綻させないようにしてください。

---

## 1. 基本原則

- **日本の漫画の読順**: **右→左**、**上→下**
- 複数のコマやセリフが**左右に並ぶ場合**は、**右が先に読むもの（前）**、**左が後に読むもの（後）**
- コマの生成順序・レイアウト・エクスポートは、すべてこの読順で一貫してプログラムで指定すること（AI任せにしない）

---

## 2. コマの左右配置

### 2.1 2コマが左右に並ぶ場合

- **右側** = 先に読むコマ（例: 2コマ目）
- **左側** = 後に読むコマ（例: 3コマ目）
- 例: 2コマ目と3コマ目が横並びなら、**右=2コマ目、左=3コマ目**

### 2.2 4コマを2×2で並べる場合（エクスポート `?layout=2x2`）

- **右列（画像の右半分）**: 1コマ目（上）、2コマ目（下） → 読順で 1 → 2
- **左列（画像の左半分）**: 3コマ目（上）、4コマ目（下） → 読順で 3 → 4
- 全体の読順: 1 → 2 → 3 → 4（右列を上から下へ、次に左列を上から下へ）

実装: `server/index.js` の `/api/comics/:date/export`（`layout=2x2` 時）で、`panelBuffers` の配置を上記のとおりプログラムで指定している。

### 2.3 縦1列ストリップ（上から1,2,3,4）

- 上から 1コマ目→2コマ目→3コマ目→4コマ目 の順で問題なし
- このストリップを外部で2列に分割して表示する場合は、**右列=1,2コマ目・左列=3,4コマ目**になるよう、表示側またはエクスポート側で制御すること

---

## 3. 1コマ内のセリフ（吹き出し）の左右

- **1コマ内にセリフが2つ以上ある場合**:
  - **右側** = 先に読むセリフ（構成で先に書かれたもの）
  - **左側** = 後に読むセリフ
- 実装:
  - **クライアント**: `client/src/utils/serifOverlay.js` で、偶数番目→右、奇数番目→左に振り分け
  - **サーバー（画像生成プロンプト）**: 「1コマ内にセリフが2つ以上ある場合、先に書かれたセリフは右側、後に書かれたセリフは左側に配置すること」と明示

---

## 4. AIプロンプトでの明示

以下の処理で、読順をプロンプトに含めること。

- **結合コマ画像生成**（`buildCombinedPanelImagePrompt`）:
  - 「日本の漫画の読順：右から左へ読む。複数のコマが左右に並ぶ場合は、右が前のコマ、左が後のコマとすること。」
  - 「1コマ内にセリフが2つ以上ある場合、先に書かれたセリフは画像の右側に、後に書かれたセリフは左側に配置すること。」
- **構成シナリオ生成**（`suggest_structure`）:
  - 「1コマ内に複数セリフを書く場合、先に書いたセリフが右側（先に読む）、後に書いたセリフが左側（後に読む）で描画される。日本の漫画は右から左へ読む。」

---

## 5. 変更時のチェックリスト

- [ ] コマを左右に並べる処理を追加・変更した場合、**右=前のコマ・左=後のコマ**になっているか
- [ ] 2×2や横並びのエクスポートを追加・変更した場合、**読順 1→2→3→4** が崩れていないか
- [ ] セリフの吹き出し配置を変更した場合、**先のセリフ=右・後のセリフ=左**になっているか
- [ ] 新しいAIプロンプトでコマやセリフのレイアウトに触れる場合、**右から左へ読む**旨を明示したか
